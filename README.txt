青いシャツのねこ 季節スタンプLP

使い方：
1. このZIPを解凍します。
2. index.html をダブルクリックします。
3. ブラウザでLPが表示されます。

中身：
- index.html：LP本体
- images/season-stamps-preview.png：スタンプ一覧画像

後で変更する場所：
- LINE STOREの販売URLが決まったら、index.html内の https://store.line.me/ を実際のURLに差し替えてください。
- 画像を差し替えたい場合は、images/season-stamps-preview.png を同じ名前で上書きしてください。
